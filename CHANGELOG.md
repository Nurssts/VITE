# Changelog

## 3.0.0 — 2026-11-22 · VITE Strategist

### Новое
- **VITE Strategist** (`#/ai`): AI-аналитик с агентным циклом. Сам планирует шаги и вызывает
  16 инструментов над локальной базой (рейтинги, профили, синергия, Монте-Карло, прогнозы
  матчей, партнёры, пробелы скаутинга, аномалии, поиск заметок). Изменения драфта, заметок и
  наблюдений выполняет только после подтверждения. Стриминг, история чатов, память AI, отзывы,
  счётчики расхода.
- **Миссии в один клик**: брифинг перед матчем, пик-лист, план скаутинга, разбор команды,
  проверка данных. Доступны с экранов «Обзор», «Матчи», «Команды», «Драфт».
- **AI-диктовка (Scribe)**: голос или текст превращаются в заполненную форму скаутинга.
- **AI Engine на сервере**: Anthropic (официальный SDK) и любой OpenAI-совместимый провайдер
  (Gemini, OpenAI, DeepSeek, Qwen, Groq, OpenRouter, Ollama), fallback, ретраи, таймауты,
  дневные бюджеты, учёт токенов.

### Исправлено
- После разрешения хранения VITE ошибочно предлагал «восстановить» только что записанные
  демо-данные.

### Удалено
- Неподключённые эндпоинты `/api/gemini/*` и устаревший `google-generativeai` (заменены AI Engine).

## 2.1.0 — 2026-11-22

### Новое
- **Страница «Матчи»**: официальное расписание и результаты ивента (FTCScout, без ключа), прогноз
  каждого матча по скаутингу и по OPR, лидеры OPR, точность модели на сыгранных матчах (Brier).
- **Скаутинг по позиции**: выберите R1/R2/B1/B2 — команда подставляется из расписания, после
  сохранения форма переходит к следующему матчу.
- Крупные кнопки +/− для подсчёта, живой итог очков, предупреждение о повторной записи матча,
  редактирование записей, «Отменить» после сохранения и удаления.
- **Объединение данных скаутов**: JSON/CSV других устройств добавляются без дублей.
- Профиль команды: история матчей, заметки, OPR, официальные победы, удаление с отменой.
- «Кого скаутить дальше» на обзоре, подбор лучшего партнёра в «Синергии», поиск на доске драфта.
- Восстановление из резервной копии IndexedDB, защита хранилища от очистки, индикатор сохранения.
- Hash-навигация: «Назад» в браузере и перезагрузка сохраняют экран.

### Исправлено
- Запрос рейтингов FTCScout и поиск команды по номеру были сломаны (пустой ответ без ошибки).
- Сезон FIRST API передавался как год окончания (2027) — исправлено на год начала (2026).
- Вкладки «Правовой информации» всегда были на русском; 268 строк интерфейса без перевода на английский.
- Заголовок «Настройки турнира» был невидим (чёрный текст на чёрном фоне).
- Поиск ивентов отправлял запрос на каждую букву, пока список не загрузился.
- Селекторы в «Синергии» пересоздавались при каждом рендере, результаты симуляции оставались от старых команд.
- Toast мог закрываться раньше времени; Esc не закрывал окна; цифры 1–9 срабатывали вместе с Ctrl.
- Service worker кэшировал ответы с ошибками.
- Ошибка записи в localStorage (квота) молча роняла приложение.

### Производительность
- Начальный JS: 714 КБ → 282 КБ (gzip 205 → 92 КБ); графики грузятся только на нужных страницах.
- Расчёт страницы драфта (60 команд × 10 матчей): 80 мс → 3 мс (данные изменились), 1,6 мс (повторный рендер).
- Шрифт Inter поставляется с приложением: нет запросов к Google, работает офлайн.

### Безопасность
- CSP, X-Frame-Options, nosniff, Referrer-Policy, Permissions-Policy.
- Валидация и ограничение размеров всех импортируемых данных; защита CSV от формул при экспорте.
- AI: валидация запросов, дневной лимит вызовов, без утечки текста ошибок SDK.
- Зависимости: gql/aiohttp и устаревший google-generativeai удалены; `npm audit` — 0 уязвимостей.

### Инженерия
- Тесты: 35 frontend (vitest, включая компонентные) + 17 backend (pytest); ESLint; CI запускает всё.
